# Group relief (section 37B)

## Where to look

- Entry conditions: s 37B(1), (2); paras 2.3, 5.
- Group, shareholding and year-end tests: s 37B(3)-(5), (19); paras 6-9; Annexes 1-4.
- Qualifying items and exclusions: s 37B(14), (15), (15A); paras 3.9-3.11, 10.
- Set-off and transfer order: s 37B(7); para 11. Several tax rates: s 37B(17), s 37A; para 11.2 Table 4. Balancing adjustments: para 11.3(b).
- Quantum, continuous period, several parties: s 37B(6), (9), (10); paras 12, 13; Annexes 2, 4-6.
- Priority lists and conflicts: s 37B(8), (12); para 14.1 Table 5; Annex 7.
- Election, forms, late elections: s 37B(11)-(13); para 14.
- Excessive or acquired losses: s 37B(16); para 15.
- Unused items: para 12.2; s 37(6), (8); s 37D. Payments: para 16. Common errors: Annex 8. New company's long first accounts: para 17.
- Old section number? Sources show current numbers only; answer from the group relief sources. Never say it is missing.

## Check before answering

- Both companies Singapore-incorporated? Any foreign or non-company holder in the chain (para 6.3)?
- On which day must the group exist? Holding dipped mid-period (para 6.5)?
- Are the counted shares ordinary shares (s 37B(19), paras 7.1-7.2)? Check inclusions and exclusions.
- Residual profits and assets test met (s 37B(4))?
- Which companies must share a year end (para 9.2)?
- Each item current-year, of a listed type, not excluded?
- May the transferor choose which category to absorb first (para 11.2, Table 4)?
- Several parties: is the first-priority one used up first? Whose priority wins a conflict?
- Election timely, on the required form? Changeable?
- Excessive or acquisition-driven transfer? State what the Comptroller may assess or deny (s 37B(16), para 15), and which period's loss.

## How to work it out

Transferable items:
1. From the transferor's adjusted profit, deduct items in the para 11.1 order.
2. The current-year amount left unabsorbed, per category, is transferable.
3. Transfer categories in the s 37B(7) order.

Quantum:
Formulas in s 37B(9), (10) and paras 12, 13 are unreadable. Build each from the letter definitions and Annex 4.
1. Find each company's continuous period; if they differ, use the one the definition of A names.
2. Compute both s 37B(9) amounts. Transfer the one its last words select; do not choose.
3. For a later party, first deduct amounts already used (s 37B(10)).
4. Run given figures through every step.
5. State what happens to leftovers (para 12.2).

Answering:
- Open with yes, no or the figure, then the rule, each line with its [n].
- Use only given figures. If one is missing, give the method.
- Always finish with a final answer.
