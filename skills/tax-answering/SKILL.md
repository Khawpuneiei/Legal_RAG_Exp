# Answering Singapore income tax questions from numbered sources

## Steps

1. Name the exact issue asked.
2. Find the governing Act provision and its guide paragraphs. If the question names a section, answer from it only if its heading matches the question's subject (old-number rule).
3. List the conditions, exceptions, limits and ordering rules. Check each against the facts.
4. Take the year or event the rule is keyed to from the source. Never assume it.
5. Apply the source's method to the question's figures.
6. Reply: direct answer first, then the conditions and exceptions that matter. Cite every statement as [n], only from sources that say it. For a partial answer, say which part is not covered.
7. Only if no source answers any part, reply with the exact refusal sentence and nothing else.

## Rules that always apply

- Use only the numbered sources. Never answer from memory.
- State figures, sections and conditions exactly as the sources do. If the question gives no amount, describe the method.
- Old-number rule: sources show only current section numbers. If the named section's heading does not match the question's subject, the number is old: answer from the source whose heading matches. Never refuse over a missing old number.
- Commit to the branch the facts select. Name an alternative only when a needed fact other than a date is missing; with no date, use the latest version stated.
- Never contradict yourself (first sentence and conclusion must agree) or invent distinctions the source does not make.
- Use another relief's guide only if the question or a cited paragraph brings it in, never for a fallback the facts or rule exclude.
- Keep reasoning short: skip checks that do not bear on the question. Reply once you reach a conclusion.
- Under 200 words. No headings.

## Common mistakes

- **Empty reply, or refusal when the sources answer.** Write the answer sentence first. Before refusing, scan every source's heading and text for the question's subject and operative terms. Refuse only if none states the rule.
- **Missed restriction or extension.** After a waiver, election or exception, read the rest of that paragraph and the next. Watch for "subject to", "only", "also". Reread a paragraph before calling it silent. Name any restriction that follows, not only the entry condition.
- **Wrong reference point.** When items have their own dates, test each against the event. A right figure does not prove the right rule.
- **Reversed calculation.** Act formulas lose their symbols: letters on separate lines are a fraction; a stray character may be a plus sign. Rebuild the operation from the definitions and any worked example, then test a sample number.
- **Over-hedging.** Delete alternatives the facts rule out and conditions that do not change the answer.
- **Wrong provision.** Check the section governs the person asked (the company, not its shareholders). If no source covers the subject, give the exact refusal sentence, or a partial answer if part is covered. Never claim the Act lacks the provision.
